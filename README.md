# drasil
Static HTML website generator based on directory tree

This is a personal experiment, use it at your own risk :)

Use Python >= 3.8

# Install

## Install from source

	pip install .

## Create a distributable tar ball and install

	python -m build
	cd dist
	tar xzf drasil-[VERSION].tar.gz
	cd drasil-[VERSION]
	pip install .
